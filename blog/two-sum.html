两数之和

2026年10月29日 · 约 1 分钟
  • Hot100
  • 算法

题目链接：1. 两数之和 - 力扣（LeetCode）

很简单一道题目，O(n^2)的做法很简单就是两层for循环扫一下。 O(nlogn)的做法也很简单就是开个map记录一下，每次都是找有没有配对的数，可以做到nlogn

代码如下：

#include <vector>
#include <unordered_map>
using namespace std;

class Solution {

public:

    vector<int> twoSum(vector<int>& nums, int target) {
        unordered_map<int, int> mp;
        for(int i = 0; i < nums.size(); i++){
            int y = target - nums[i];

            if(mp.find(y) != mp.end()){
                return {mp[y], i};
            }

            mp[nums[i]] = i;

        }

        return {};

    }

};
